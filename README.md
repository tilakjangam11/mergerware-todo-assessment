# MergerWare Simple Todos — Technical Assessment

A todo app built with Meteor.js and Blaze templates for the MergerWare Software Engineering Internship assessment.

## Features
- Add and delete tasks
- Mark tasks as complete
- Task Categories (Work, Personal, Urgent) with filter
- Drag and Drop reordering (order saved in MongoDB)

## Tech Stack
- Meteor.js
- Blaze Templates
- MongoDB
- JavaScript ES6+

## How to Run
1. Install Meteor from https://www.meteor.com/install
2. Clone this repo
3. Run: meteor run
4. Open: http://localhost:3000

## Assessment Requirements Covered
- Base Simple Todos tutorial implemented
- Task Categories added with filter functionality
- Drag and Drop reordering with MongoDB persistence
